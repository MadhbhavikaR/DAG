## Documentation rules

- Keep this index and all linked guides current.
- Architecture Decision Records (ADR) capture a decision, context, alternatives, rationale and consequences.
- Decision Analysis and Review (DAR) records capture decision criteria, evidence, options, trade-offs, risks and review outcome.
- Do not mark planned features as implemented.
