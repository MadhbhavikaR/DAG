# Decision Analysis and Review

DAR records analyze a decision before or after implementation. Use them for alternatives, evidence, trade-offs and review outcomes.

## Required format

1. Decision statement and scope.
2. Date, status and participants.
3. Problem and constraints.
4. Decision criteria and relative importance.
5. Options considered, including a do-nothing option.
6. Evidence and assumptions (clearly separated).
7. Comparative analysis and trade-offs.
8. Risk analysis and mitigations.
9. Recommendation and rationale.
10. Review outcome, validation evidence and revisit triggers.
11. References.

Do not present assumptions as measured facts. Record unknowns as explicit discovery tasks.
